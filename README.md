# Full Stack MERN iMovies

A movie ticket booking application built with a separate frontend
and Node.js/Express backend.

## Project Structure

- frontend/ — HTML, CSS and JavaScript
- backend/ — Node.js, Express and MongoDB API

## Requirements

- Node.js
- npm
- MongoDB

## Running the Backend

1. Navigate to the backend folder.
2. Install dependencies using npm install.
3. Configure the environment variables in .env.
4. Start the server using the script defined in package.json.

## Frontend

The backend serves the frontend on the configured local port.
